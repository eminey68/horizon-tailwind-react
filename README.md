# KİÜ Kaynak Yönetim Platformu 🎓

Bu proje, Kahramanmaraş İstiklal Üniversitesi için özel olarak geliştirilmiş, modern ve dinamik bir kaynak (laboratuvar, amfi, toplantı odası vb.) rezervasyon ve yönetim sisteminin kullanıcı arayüzüdür (Frontend).

## 🚀 Proje Özellikleri

* **Rol Bazlı Dinamik Mimari (RBAC):** Sisteme giriş yapan kullanıcının yetkisine göre (Öğrenci, Akademisyen, Yönetici) arayüz, istatistik kartları ve yetkiler anında şekillenir.
* **Canlı Arama (Live Search):** Tablolarda sayfa yenilemeye veya enter tuşuna basmaya gerek kalmadan, klavye girdisiyle eş zamanlı çalışan yüksek performanslı filtreleme.
* **Modern UI/UX (Glassmorphism):** Kullanıcı deneyimini artırmak için Apple standartlarında cam efektleri, yarı saydam form yapıları ve akıcı animasyonlar kullanılmıştır.
* **İnteraktif Bildirim Merkezi:** Kullanıcı aksiyonlarını takip eden, okunmamış mesaj bildirimleri sunan canlı dropdown bildirim sistemi.
* **Akıllı Rezervasyon Yönetimi:** Geçmiş ve gelecek rezervasyonların ayrıştırılması, yaklaşan rezervasyonlar için dinamik iptal onayı pencereleri (Modal).

## 💻 Kullanılan Teknolojiler
* React.js
* Tailwind CSS (Özelleştirilmiş stiller ve cam efektleri)
* React Router DOM (Sayfa yönlendirmeleri)
* React Icons (Feather Icons ve Material Design entegrasyonu)
